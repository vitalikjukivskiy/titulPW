# Титули CyberPW

Онлайн-довідник ланцюжків титулів для Perfect World / CyberPW.

<p align="center">
  <a href="https://vitalikjukivskiy.github.io/titulPW/"><strong>🌐 Відкрити довідник титулів</strong></a>
</p>

## Що є на сторінці

- ланцюжки титулів у правильному порядку;
- назви квестів і потрібних NPC;
- моби, предмети та координати;
- прямі посилання на актуальні сторінки PWDatabase;
- зручний перегляд без встановлення програми.

## Як користуватися

1. Відкрийте [онлайн-довідник](https://vitalikjukivskiy.github.io/titulPW/).
2. Знайдіть потрібний ланцюжок або назву титулу через пошук браузера (`Ctrl+F`).
3. Виконуйте етапи зверху вниз.
4. Для автоматичних міток, прогресу та OCR використовуйте [CyberPW Assistant 0.90](https://github.com/vitalikjukivskiy/titul_helper/releases/tag/v0.90-design-preview).

## Про репозиторій

GitHub Pages публікується з гілки `main`, папка `/(root)`. Основна сторінка — `index.html`; зображення `pw-final-header.png` і `cyberpw-logo.png` зберігаються поруч.

Це неофіційний фанатський довідник. Дані можуть відрізнятися після серверних оновлень, тому про неточності можна повідомляти через [Issues](https://github.com/vitalikjukivskiy/titulPW/issues).
